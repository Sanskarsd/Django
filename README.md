# Django Learning Projects

This repository contains multiple projects developed while learning **Django and Django REST Framework (DRF)**. Each project focuses on understanding and implementing different Django concepts, features, and development practices.

## 📚 Purpose

The primary purpose of this repository is to maintain all my Django learning projects in one place, practice concepts through hands-on development, and track my progress as I learn Django.

## 🛠️ Technologies

- Python
- Django
- Django REST Framework (DRF)
- SQLite
- MySQL / PostgreSQL
- JWT Authentication
- Git & GitHub

This repository is organized into separate project folders. Each folder represents an individual project or a practical implementation of a particular Django concept.

## 📖 Topics Covered

The projects in this repository explore concepts such as:

- Django fundamentals and project structure
- Models, views, templates, and URL routing
- Database integration and ORM
- Forms and ModelForms
- User authentication and authorization
- Custom User Models
- Session-based authentication
- Basic Authentication
- Token and JWT Authentication
- Django REST Framework
- Serializers and API development
- Permissions and API security
- CRUD operations

*The topics are added progressively as I learn and implement them.*

## 🎯 Learning Approach

Each project is created to gain practical experience with Django concepts rather than just studying theory. The repository will continue to evolve as I explore more advanced Django features and build additional projects.
